# TRI Trading Simulator — online version

## Что уже работает
- Один общий серверный рынок для всех подключённых игроков.
- Начальная история свечей, цена, минутные свечи, таймер и направление синхронизируются через Socket.IO.
- Команды «РЫНОК ВВЕРХ/ВНИЗ» и операции «ПОПОЛНИТЬ/ВЫВЕСТИ» требуют пароль администратора, который проверяется только сервером.
- Команда начинает действовать после закрытия текущей минутной свечи и задаёт направление следующей свечи.
- Три общих инструмента: золото, BTC и ETH. Выбор инструмента одним игроком меняет его для всех.

## Важно
Это учебный симулятор с виртуальными деньгами, не биржа и не финансовый продукт. В этой первой онлайн-версии цена и график общие, но баланс и сделки хранятся в браузере каждого игрока локально. Это не защищённый серверный игровой аккаунт: продвинутый пользователь может менять локальные данные. Не используйте реальные деньги.

## Размещение на Render
1. Создайте аккаунт GitHub: https://github.com/
2. Создайте аккаунт Render: https://render.com/
3. На GitHub создайте новый репозиторий (например `tri-trading-game`) и загрузите в него все файлы этой папки.
4. В Render нажмите **New + → Web Service**, подключите GitHub и выберите репозиторий.
5. Укажите: **Runtime: Node**, **Build Command: `npm install`**, **Start Command: `npm start`**.
6. В Render откройте **Environment** и добавьте переменную `ADMIN_PASSWORD` со значением вашего пароля администратора. Не добавляйте пароль в файлы проекта и не отправляйте его игрокам.
7. Нажмите **Create Web Service**. После сборки Render выдаст публичный адрес `https://....onrender.com` — его можно отправлять игрокам.

## Локальный запуск
Требуется Node.js 18 или новее. Выполните `npm install`, задайте `ADMIN_PASSWORD` в окружении и запустите `npm start`.

## Безопасность
Если пароль администратора уже публиковался в открытом HTML/чате или его знают другие люди, смените его на новый перед публикацией. Для реального проекта добавьте серверные аккаунты, хранение балансов/сделок в БД, ограничения частоты команд и журнал действий администратора.
